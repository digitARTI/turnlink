# Development status

Turnlink supports manual stop and resume of a session in a chosen destination.
The operator is responsible for confirming that the source is stopped and for
reviewing external work before resuming. See [migration resume](migration-resume.md)
and [managed worktrees](worktree-lifecycle.md).

Automatic live transfer and native writer-exclusion guarantees are not part of
the supported workflow. Historical development evidence is retained on the
experimental branch. Remaining operational work includes storage acceptance,
alert installation, and Windows, IDE, and live-model acceptance.
