# Turnlink brand assets

The name combines conversation turns with the link between agents. The mark uses two offset loops, a short connecting stroke, and a small signal dot.

<img src="assets/wordmark.svg" alt="Turnlink wordmark" width="480" />

## Files

| Asset | Use |
| --- | --- |
| [Color logo](assets/logo.svg) | Square icon on a charcoal background; scalable SVG source. |
| [PNG icon](assets/logo.png) | 512px raster version for avatars and tools that need PNG. |
| [Monochrome mark](assets/logo-mono.svg) | Transparent background with a dark mark for light surfaces. |
| [Wordmark](assets/wordmark.svg) | Horizontal name and mark on a dark background. |
| [README banner](assets/banner.svg) | Project heading and harness/remote connection diagram. |

## Palette

| Color | Hex | Use |
| --- | --- | --- |
| Charcoal | `#101c2c` | Background |
| Mint | `#66e3bf` | First conversation loop |
| Soft blue | `#8eb5ff` | Second conversation loop |
| Ice | `#eef5ff` | Connecting stroke and wordmark |
| Amber | `#e9bd70` | Signal dot |

Keep the icon square and preserve its padding. Use the monochrome asset on light backgrounds. The wordmark uses Arial/Helvetica system fallbacks and does not require downloading a font.

The public project and package name are **Turnlink** / `turnlink`. Existing protocol tools, MCP configuration keys, deployment filenames and runtime paths use `agent-channel` where required by the installed integrations. New source installations can live in a `turnlink` directory.
